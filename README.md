# StealthKeep v2.2.1
ห้องนิรภัยดิจิทัลแบบ PWA (HTML + Vanilla JS + Tailwind) — ข้อมูลเข้ารหัส AES-256-GCM ในเครื่อง (คีย์มาจาก PIN ผ่าน PBKDF2)

## ติดตั้งผ่าน GitHub Pages
1. สร้าง repo ใหม่ → อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (branch `main`)
2. Settings → Pages → Source เลือก **GitHub Actions** (workflow `pages.yml` จะ deploy ให้อัตโนมัติ)
3. เปิด `https://<user>.github.io/<repo>/` บนมือถือ

## เพิ่มไอคอนบนหน้าหลักมือถือ
- **Android (Chrome):** เมนู ⋮ → “ติดตั้งแอป” หรือปุ่ม “เพิ่มไอคอนลงหน้าจอหลัก” ในหน้าตั้งค่า (กดไอคอนค้างจะมีทางลัด โน้ตลับ / เช็คลิสต์ / เอกสาร)
- **iPhone (Safari):** ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”

## เชื่อม Google Sheets (ไม่บังคับ — ใช้กับอัลบั้ม และซิงก์สำรอง)
1. สร้าง Google Sheet → Extensions → Apps Script → วางโค้ดจาก `Code.gs` แก้ `TOKEN`
2. Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone)
3. นำ URL + Token ไปใส่ในแอป: ตั้งค่า → Google Sheets Backend
4. **ทุกครั้งที่แก้ `Code.gs`** ต้อง Deploy → Manage deployments → ✏️ → Version: New version (ไม่เช่นนั้นสคริปต์ยังเป็นโค้ดเก่า)

## หมายเหตุ
- ลืม PIN = กู้ข้อมูลไม่ได้ (ออกแบบมาเช่นนั้น) — สำรองไฟล์ JSON ไว้เสมอ
- ต้องอัปเดต `VERSION`, `CACHE` ใน `sw.js` และ `VER` ใน `index.html` ทุกครั้งที่ปล่อยเวอร์ชันใหม่

## สำรอง / กู้คืน / ใช้หลายเครื่อง
- **สำรอง:** ตั้งค่า → “สำรองข้อมูล & กู้คืน” → สำรองเป็นไฟล์ (แนะนำตั้งรหัสผ่านไฟล์ ≥ 8 ตัว) หรือใช้ Google Sheets → ส่งขึ้น
- **ล้างเครื่อง/เครื่องใหม่:** เปิดแอป → ที่หน้าตั้ง PIN กด “กู้คืนจากไฟล์สำรอง” หรือ “กู้คืนจาก Google Sheets” → ใส่ PIN ของข้อมูลสำรอง
- **หลายเครื่อง:** กู้คืนข้อมูลชุดเดียวกันลงทุกเครื่อง แล้วซิงก์ด้วย “ส่งขึ้น/ดึงลง” (ซิงก์ด้วยตนเอง ไม่รวมข้อมูลอัตโนมัติ — เครื่องที่ส่งขึ้นทีหลังจะทับ) เปลี่ยน PIN เครื่องหนึ่งแล้วเครื่องอื่นต้องกู้คืนใหม่
- **สำรองอัตโนมัติ:** ตั้งค่า → Google Sheets → ตั้ง “รหัสผ่านสำรอง” (แยกจาก PIN) แล้วเปิดสวิตช์ “สำรองอัตโนมัติขึ้นชีต” — แอปส่งขึ้นเองหลังแก้ข้อมูล ~20 วินาที และตอนล็อก/ซ่อนแอป (เฉพาะตอนเปิดแอปอยู่) ถ้าบนชีตมีข้อมูลใหม่กว่าจากเครื่องอื่นจะหยุดและแจ้งให้ “ดึงลง” ก่อน — **จดรหัสผ่านสำรองไว้ ลืม = กู้คืนจากชีตไม่ได้**
