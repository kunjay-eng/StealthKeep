# StealthKeep v2.23.0
ห้องนิรภัยดิจิทัลแบบ PWA (HTML + Vanilla JS + Tailwind) — ข้อมูลเข้ารหัส AES-256-GCM ในเครื่อง (คีย์มาจาก PIN ผ่าน PBKDF2)

## ติดตั้งผ่าน GitHub Pages
1. สร้าง repo ใหม่ → อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (branch `main`)
2. Settings → Pages → Source เลือก **GitHub Actions** (workflow `pages.yml` จะ deploy ให้อัตโนมัติ)
3. เปิด `https://<user>.github.io/<repo>/` บนมือถือ

## เพิ่มไอคอนบนหน้าหลักมือถือ
- **Android (Chrome):** เมนู ⋮ → “ติดตั้งแอป” หรือปุ่ม “เพิ่มไอคอนลงหน้าจอหลัก” ในหน้าตั้งค่า (กดไอคอนค้างจะมีทางลัด โน้ตลับ / เช็คลิสต์ / เอกสาร)
- **iPhone (Safari):** ปุ่มแชร์ → “เพิ่มไปยังหน้าจอโฮม”

## เชื่อม Google Sheets (ไม่บังคับ — ใช้กับอัลบั้ม และซิงก์สำรอง)
1. สร้าง Google Sheet → Extensions → Apps Script → วางโค้ดจาก `Code.gs` แก้ `TOKEN`
2. Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone)
3. นำ URL + Token ไปใส่ในแอป: ตั้งค่า → Google Sheets Backend
4. **ทุกครั้งที่แก้ `Code.gs`** ต้อง Deploy → Manage deployments → ✏️ → Version: New version (ไม่เช่นนั้นสคริปต์ยังเป็นโค้ดเก่า)

## เช็คลิสต์: หัวข้องาน (หลายเช็คลิสต์ / เช็คลิสต์เดียว)
- เมนู เช็คลิสต์ → แถบด้านบน: “📋 งานเดี่ยว” (ภารกิจเดี่ยวแบบเดิม) / “📁 หัวข้องาน” แต่ละหัวข้อ / “＋ หัวข้องาน” สร้างหัวข้อใหม่
- หัวข้อใหม่มี **เช็คลิสต์เดียว** (หัวข้อแบบหลายเช็คลิสต์ที่สร้างไว้ก่อนหน้ายังใช้ได้ และเปลี่ยนเป็นเช็คลิสต์เดียวได้) — พิมพ์ภารกิจแล้วกด ＋ หรือ Enter เพิ่มต่อเนื่องได้ และใส่ 📅 วันสิ้นสุดของภารกิจได้ (ไม่บังคับ)
- **วันสิ้นสุดของหัวข้อ = วันสิ้นสุดที่นานที่สุดของภารกิจในหัวข้อ** (แสดงที่หัวข้อและหน้าแรก)
- **กันติ๊กออกพลาด:** ภารกิจที่ติ๊กเสร็จแล้วจะล็อกช่องติ๊ก (กดไม่ได้) ถ้าต้องการยกเลิกให้กดปุ่ม ↩ แล้วยืนยัน
- เลือกหัวข้อไปแสดงที่หน้าแรก: กด 📌 ที่หัวข้อ หรือเปิด “แสดงที่หน้าแรก” ในหน้าแก้ไข — หน้าแรกจะโชว์ทั้งหัวข้อ (ทุกเช็คลิสต์ + แถบความคืบหน้า) และติ๊กทำเสร็จได้เลย
- เมื่อทำครบทุกภารกิจในหัวข้อ ระบบจะ **เก็บหัวข้อเข้าคลังอัตโนมัติ** (ดูที่แท็บ “📦 คลังหัวข้อ” — ดูภารกิจ / กู้คืน / ลบถาวรได้) ส่วน “งานเดี่ยว” ทำงานเหมือนเดิม

## ลิงค์ฮับ (Link Hub) — เมนูล่างขวา
รวมระบบ Link Hub v1.0.3 เข้ามาแทนเมนู “เพิ่มเติม” (อัลบั้ม / เพลง / สร้างรูป / ตั้งค่า ย้ายไปอยู่ที่ “ทางลัด” ในหน้าแรก)
- ไม่ตั้งค่าอะไร = **โหมดทดลอง** เก็บข้อมูลในเบราว์เซอร์เครื่องนั้น
- ต้องการใช้ Google Sheets: สร้าง Sheet ใหม่ → Apps Script → วาง `linkhub/Code.gs` → Script properties เพิ่ม `ADMIN_PIN` → Deploy เป็น Web app (Anyone) → นำ URL `/exec` ไปใส่ `API_URL` ในไฟล์ `linkhub/linkhub-config.js`
- เป็นสคริปต์/ชีตคนละตัวกับ `Code.gs` ของ StealthKeep และข้อมูลลิงค์ฮับ **ไม่ได้เข้ารหัสในห้องนิรภัย** (เปิดด้วย Duress PIN จะไม่เห็นข้อมูลลิงค์ฮับ)

## หมายเหตุ
- ลืม PIN = กู้ข้อมูลไม่ได้ (ออกแบบมาเช่นนั้น) — สำรองไฟล์ JSON ไว้เสมอ
- ต้องอัปเดต `VERSION`, `CACHE` ใน `sw.js` และ `VER` ใน `index.html` ทุกครั้งที่ปล่อยเวอร์ชันใหม่

## สำรอง / กู้คืน / ใช้หลายเครื่อง
- **สำรอง (2 ขั้นตอน):** ตั้งค่า → “สำรองข้อมูล & กู้คืน” → กด “💾 สำรองข้อมูล” ระบบสร้างไฟล์สำรองให้อัตโนมัติ → เลือก “📱 บันทึกลงเครื่อง” หรือ “☁️ บันทึกลง Google Drive” (โฟลเดอร์ `StealthKeep Backups` ใน Drive ของบัญชีที่ Deploy สคริปต์) — Drive ต้องตั้ง URL/Token ของ Google Sheets Backend และใช้ `Code.gs` v2.3.0 ขึ้นไป (วางโค้ดใหม่แล้ว Deploy → New version) • ถ้าตั้ง “รหัสผ่านสำรอง” ไว้ แอปใช้รหัสนั้นเข้ารหัสไฟล์ให้เอง ไม่ถามซ้ำ • หรือใช้ Google Sheets → ส่งขึ้น
- **ล้างเครื่อง/เครื่องใหม่:** เปิดแอป → ที่หน้าตั้ง PIN กด “กู้คืนจากไฟล์สำรอง”, “กู้คืนจาก Google Sheets” หรือ “กู้คืนจาก Google Drive” (ใส่ URL + Token ของสคริปต์ → เลือกไฟล์จากรายการ ต้องใช้ `Code.gs` v2.4.0 ขึ้นไป) → ใส่ PIN ของข้อมูลสำรอง
- **หลายเครื่อง:** กู้คืนข้อมูลชุดเดียวกันลงทุกเครื่อง แล้วซิงก์ด้วย “ส่งขึ้น/ดึงลง” (ซิงก์ด้วยตนเอง ไม่รวมข้อมูลอัตโนมัติ — เครื่องที่ส่งขึ้นทีหลังจะทับ) เปลี่ยน PIN เครื่องหนึ่งแล้วเครื่องอื่นต้องกู้คืนใหม่
- **สำรองอัตโนมัติ:** ตั้งค่า → Google Sheets → ตั้ง “รหัสผ่านสำรอง” (แยกจาก PIN) แล้วเปิดสวิตช์ “สำรองอัตโนมัติขึ้นชีต” — แอปส่งขึ้นเองหลังแก้ข้อมูล ~20 วินาที และตอนล็อก/ซ่อนแอป (เฉพาะตอนเปิดแอปอยู่) ถ้าบนชีตมีข้อมูลใหม่กว่าจากเครื่องอื่นจะหยุดและแจ้งให้ “ดึงลง” ก่อน — **จดรหัสผ่านสำรองไว้ ลืม = กู้คืนจากชีตไม่ได้**
